# Create a payment

When you create a payment using the API, you will get a redirect URL. You should redirect the buyer to this URL so they can complete the payment on our checkout page.

## Create a payment

<mark style="color:green;">`POST`</mark> `https://api.dlocalgo.com/v1/payments`

#### Headers

| Name                                            | Type   | Description                  |
| ----------------------------------------------- | ------ | ---------------------------- |
| Authorization<mark style="color:red;">\*</mark> | string | Bearer \[api*key:secret*key] |

#### Request Body

### Sample API call

{% code fullWidth="false" %}

```sh
curl --location 'https://api-sbx.dlocalgo.com/v1/payments' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer API_KEY:API_SECRET' \
--data '{
    "currency": "BRL",
    "amount": 500,
    "country": "BR",
    "order_id": 83778,
    "description": "Order 83778 - example.com",
    "success_url": "https://example.com/success",
    "back_url": "https://example.com/",
    "notification_url": "https://example.com/notifications"
}'
```

#### **`Payer`** object

All attributes will be mandatory in the checkout process if not provided in the initial request.

<table data-header-hidden><thead><tr><th width="195.33333333333331"></th><th width="154"></th><th></th></tr></thead><tbody><tr><td><strong>Attribute</strong></td><td><strong>Type</strong></td><td><strong>Description</strong></td></tr><tr><td><code>id</code></td><td><em>string</em></td><td>Unique identifier for the payer on the merchant's side. It will be automatically generated if not provided.</td></tr><tr><td><code>name</code></td><td><em>string</em></td><td>Full name of the payer. Maximum length: 100 characters.</td></tr><tr><td><code>email</code></td><td><em>string</em></td><td>Email address of the payer. Maximum length: 100 characters.</td></tr><tr><td><code>phone</code></td><td><em>string</em></td><td>Payer's phone number. Maximum length: 100 characters.</td></tr><tr><td><code>document_type</code></td><td><em>string</em></td><td><p>Payer's document type.</p><p>Must be a valid document type for the specified country</p></td></tr><tr><td><code>document</code></td><td><em>string</em></td><td>Payer's document number. **Valid document types**

* Argentina (AR): DNI, CUIT, CUIL
* Bolivia (BO): CI, NIT
* Brasil (BR): CPF, CNPJ
* Chile (CL): RUN, RUT
* Colombia (CO): CC, NIT, CE, PASS
* Costa Rica (CR): CI, CR, CJ
* Ecuador (EC): CI, RUC
* Guatemala (GT): CUI, NIT
* Indonesia (ID): NIK
* Kenia (KE): ID
* Malasia (MY): NRIC
* México (MX): CURP, RFC, IFE, PASS
* Nigeria (NG): NIN
* Panamá (PA): CIP, PASS, RUC
* Perú (PE): CE, DNI, PASS, RUC
* Paraguay (PY): CI, RUC
* Uruguay (UY): CI, RUT
