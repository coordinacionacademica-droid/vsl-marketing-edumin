# Authentication

The dLocal Go API employs API keys for request authentication. You can view and manage your API keys within each environment.

## <mark style="color:blue;">Security</mark>&#x20;

All requests are transmitted securely over HTTPS and authenticated using Bearer authentication.&#x20;

The authentication key is generated by concatenating your API key with your Secret key in the format: `<API_KEY>:<SECRET_KEY>`."

**Bearer authentication:** `<API_KEY> + ":" + <SECRET_KEY>`

{% code title="Example Bearer" %}

```
$ curl -X POST 
https://api.dlocalgo.com/v1/me -H 
"Content-Type: application/json" -H 
"Authorization: Bearer <API_KEY>:<SECRET_KEY>" -d ‘...’
```

{% endcode %}

{% hint style="danger" %}
Never expose your secret key in a public repository. Remember, you are handling sensitive data. Always prioritize security on your server.&#x20;
{% endhint %}
